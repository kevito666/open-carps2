# Contributing

Bug reports, trace interpretations, independently written code, and tests are welcome.
For hardware reports, include exact model, revision if known, connection type, CUPS
version, kernel, test case, actual result, and whether the test printed on real hardware.

**Do not submit proprietary Canon packages, drivers, copied source, firmware, manual
scans, private documents, raw print jobs, IP addresses or device serial numbers.**
Only include independently created or appropriately licensed code. Explain provenance
and relevant license for every imported file.

Do not make untested printer support claims. Model status must be updated alongside tests.
